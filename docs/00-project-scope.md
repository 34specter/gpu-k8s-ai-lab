# 项目范围与实验边界

## 定位

本仓库记录 NCP-AIN 双节点 GPU 实验环境的部署、验证和问题闭环，覆盖基础设施、容器、Kubernetes、高速网络、分布式训练和推理服务。

## 边界

- 目标环境是两台节点的实验集群，不等同于生产级大规模交付。
- 节点地址、证书、密钥、模型权重和原始日志不进入仓库。
- 版本和指标是实验记录的起点；任何环境变化都应重新验证。
- 文档中的“已完成”必须能关联命令输出、指标或脱敏证据。

## 分层模型

1. 主机与 GPU：Linux、驱动、时间同步、GPU 可见性。
2. 容器与集群：containerd、Harbor、kubeadm、Calico、Device Plugin。
3. 网络与通信：RoCE/IB、RDMA、GID、NCCL 和监控。
4. 工作负载：PyTorch DDP/LoRA、KubeRay/vLLM、模型存储和 API。

## 记录原则

区分“计划”“待验证”“已验证”和“已复现”。共同完成或按文档复现的工作，在对外材料中使用准确的参与程度描述。
